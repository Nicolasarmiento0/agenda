# Roadmap

MVP completo y operativo. Orden de las próximas features:

1. **Notificaciones push con segmentación por rol** — recordatorios al cliente (24h/1h antes) y alertas al trabajador ante nueva reserva/cancelación. Reduce no-shows.
2. **Reseñas post-servicio + NucoraPoints** — valoraciones (1-5 estrellas + comentario) desbloqueadas al completar la cita; puntos canjeables por descuentos.
3. **Panel de analytics para la empresa** — ocupación por trabajador, servicios más demandados, horas pico.
4. **Modo offline con sincronización diferida** — cache local de agenda del trabajador, sync automático al reconectar.
5. **Widget de reserva embebible** — iframe/snippet para incrustar el flujo de `/{slug}` en sitios web externos.
